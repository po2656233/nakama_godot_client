<h1> 折纸屋 </h1>

><b>融合社交与多游戏的平台</b>
欢迎来到 [折纸屋](https://www.trytry.asia)，这是一个融合了社交与游戏的创新平台。在这里，您不仅可以享受丰富多彩的游戏体验，还可以与全球玩家互动，建立深厚的社交关系。

## 项目概述

**折纸屋** 是一个集社交与游戏于一体的平台，旨在为用户提供沉浸式的娱乐体验。平台分为两大核心模块：**社交** 和 **游戏**。通过社交模块，用户可以建立和维护社交关系；通过游戏模块，用户可以参与多种类型的游戏，体验不同的赛制和挑战。

## 平台特色

- **📱 跨平台支持**：支持PC、移动设备等多平台，随时随地畅玩游戏。
- **🎤 实时语音聊天**：内置实时语音聊天功能，方便玩家在游戏中沟通。
- **🎨 个性化定制**：丰富的角色和场景定制选项，打造独一无二的游戏体验。

## 社交模块

- **🌍 世界** 是一个全球社交广场，用户可以在这里发布动态、分享游戏心得、参与话题讨论，与全球玩家互动。

- **🏠 俱乐部** 是用户组建或加入的兴趣小组。俱乐部成员可以共同参与游戏、组织活动、分享资源，打造专属的社交圈。

- **👫 好友** 系统允许用户添加和管理好友关系。用户可以查看好友的游戏信息、在线状态，并与好友进行私聊或组队游戏。

## 游戏模块
#### 类型
- **🎲 随机匹配型** 游戏模式允许用户快速匹配到其他玩家，进行即时对战。适合喜欢快节奏游戏的玩家。

- **🏠 自主房间型** 游戏模式允许用户创建或加入自定义房间，选择不同的游戏模式和赛制，与好友或其他玩家进行对战。

#### 模式
- **🏆 积分模式**：玩家通过比赛积累积分，提升排名。
- **💰 金币模式**：玩家通过比赛赢得金币，可用于购买游戏内道具。
- **💎 钻石模式**：玩家通过比赛赢得钻石，可用于兑换稀有物品或参与高级赛事。

#### 赛制
- **📏 标准赛制**：常规比赛模式，适合日常娱乐。
- **🏅 锦标赛制**：周期性比赛，设有丰厚奖励，适合竞技玩家。
- **🌍 世界杯赛制**：全球性大赛，顶尖玩家同台竞技，争夺最高荣誉。

### 游戏排行榜
- **📊 游戏排行榜** 实时更新玩家的排名信息，展示全球顶尖玩家的成绩。用户可以通过排行榜了解自己的竞技水平，并挑战更高排名。

### 个人游戏记录
- **📝 个人游戏记录** 记录了用户的游戏历史、胜率、成就等信息。用户可以通过查看记录，分析自己的游戏表现，制定提升策略。

## 其他功能

### 成就系统
- **🏅 成就系统** 鼓励用户完成各种挑战，解锁成就徽章，展示自己的游戏实力。

### 商城系统
- **🛒 商城系统** 提供丰富的游戏道具和装饰品，用户可以使用金币或钻石购买，个性化自己的游戏体验。

### 客服支持
- **📞 客服支持** 为用户提供全天候的咨询服务，解决游戏中的问题，确保良好的用户体验。

## 项目结构

```
core/              平台底层
  bootstrap/       Global / Util / Errors（autoload）与 global_config.cfg
  network/         Online* / MessageQueue（Nakama 封装）
  scene/           SceneMgr、路由表、转场、叠加页
  navigation/      SceneRouter + NavigationContext（进入/退出与上下文回退）
  services/        SignalMgr / SettingsMgr / DataMgr / MailMgr
  window/          无边框窗口、消息框
  framework/       子游戏插件契约（GameMetadata / GameBase* / GameHostBridge / GameRegistry / GameLauncher）
shared/            跨模块共享
  ui/              通用 UI（加载、设置、弹窗、排行榜、返回按钮…）
  avatar/          原生骨骼动画门面（DragonBones 平替）
  utils/ styles/   工具类、主题/字体/Shader
lobby/             大厅与社交：home chat club room match gamelist email approval announcement
app/               应用外壳页：login register
games/<key>/       子游戏插件（自包含）：game_meta.tres + entry.tscn + scripts/ + assets/
assets/            共享美术/音频/字体
docs/              架构、子游戏接入指南、重构记录
tools/             headless 校验与迁移工具
```

新增子游戏请看 [docs/GAME_DEVELOPMENT.md](docs/GAME_DEVELOPMENT.md)；
分层与服务职责见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)；
本次插拔化重构的变更记录见 [docs/CHANGELOG_PLUGIN.md](docs/CHANGELOG_PLUGIN.md)。
